# MySurf: Caloundra Surf Check

Live surf forecast for **Happy Valley** and **Moffat Beach**, Caloundra (Sunshine Coast, QLD).

- Hourly swell, wind, tide and weather from [Open-Meteo](https://open-meteo.com/) (wind from BOM ACCESS-G where available)
- 0–10 rating and plain-English description per spot, tuned to each break's swell window, offshore wind and tide preference
- OpenStreetMap view with swell and wind overlays, plus a side-on wave diagram (face, back, period)
- Refresh button, auto-refresh every 30 min, offline cache

Single static file: `index.html`. Hosted with GitHub Pages.

Spots, coordinates and rating settings live in the `CONFIG` and `SPOTS` blocks at the top of the script.

Map data © OpenStreetMap contributors. Surf ratings are estimates; check the water yourself.
